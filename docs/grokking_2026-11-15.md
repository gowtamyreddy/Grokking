# Grokking reproduction, 2026-11-15

Paper: Power et al., "Grokking: Generalization Beyond Overfitting
on Small Algorithmic Datasets" (arXiv:2201.02177).

## What grokking is

A small transformer trained on modular arithmetic memorizes the
training set fast, then, long after train accuracy hits 100%,
validation accuracy suddenly jumps to ~100%. The model first
memorizes, then generalizes. That delayed jump is grokking.

## Setup

- Task: a + b mod 97. Sequence [a, b, =], prediction read off the
  last position.
- Model: one decoder layer, d_model 128, 4 heads, 225,506 params,
  built from parts in `train.py` so every piece is visible.
- Data: all 9,409 pairs; half for training (4,704), half held out
  (4,705). Full-batch training.
- Optimizer: AdamW, lr 1e-3, betas (0.9, 0.98), weight decay 1.0.
  Weight decay is the ingredient that makes it grok; without it
  the model memorizes and never generalizes.
- Hardware: sandbox CPU, 2 torch threads, 0.42 s per step.

## Result: grokked at step 1,200

Train accuracy hit 100% by step 200. Validation sat near chance
until then, then climbed and reached 99.1% at step 1,200, after
491.9 s (about 8 minutes). The run stopped there by the early-stop
rule (val >= 99%).

| step | train loss | train acc | val acc |
|-----:|-----------:|----------:|--------:|
| 1 | 4.7692 | 0.011 | 0.011 |
| 100 | 2.8215 | 0.375 | 0.011 |
| 200 | 0.1428 | 0.999 | 0.361 |
| 300 | 0.2119 | 0.994 | 0.416 |
| 500 | 0.0486 | 1.000 | 0.503 |
| 800 | 0.0257 | 1.000 | 0.635 |
| 900 | 0.0351 | 1.000 | 0.778 |
| 1000 | 0.0727 | 1.000 | 0.893 |
| 1100 | 0.0317 | 1.000 | 0.952 |
| 1200 | 0.0431 | 1.000 | 0.991 |

One honest note: the rise here is smoother than the paper's
sharpest jump. Validation was already at 0.36 by step 200 and
climbed steadily, with the steep part between steps 800 and
1,200. The defining pattern still holds, memorization at ~200
steps, generalization at 1,200, a 6x delay, but this run groks
by climbing, not by a single vertical step.

Full per-100-step log: `runs/metrics.jsonl`. Curve:
`runs/curve.png` (regenerate with `.venv/bin/python plot.py`).

## Reproduce

```bash
python3 -m venv .venv
.venv/bin/python -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv/bin/python -m pip install matplotlib
.venv/bin/python train.py            # full run, stops at val 99%
.venv/bin/python train.py --smoke    # 300 steps, checks it runs
.venv/bin/python plot.py             # writes runs/curve.png
```
